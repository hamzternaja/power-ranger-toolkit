# /solve-all Workflow

เมื่อผู้ใช้พิมพ์ `/solve-all`:

## ⚠️ กฎสำคัญ: ทำต่อเนื่องไม่หยุด!

> **ห้ามถามว่า "ต้องการทำต่อไหม?"** 
> **ห้ามใช้ notify_user จนกว่าจะทำเสร็จทั้งหมดหรือติดปัญหา**
> ทำไปเรื่อยๆ จนกว่า:
> 1. โจทย์หมด หรือ
> 2. ติด context limit หรือ
> 3. เกิด error ร้ายแรง

## ขั้นตอน:

### 1. อ่านโจทย์
อ่าน `C:\Users\chawa\.gemini\antigravity\.agent\knowledge\problems.md`
หาโจทย์ที่มี Status: ⬜ Pending

### 2. Loop แก้โจทย์ (ต่อเนื่อง!)
**วนลูปไม่หยุด** - ทำทีละ 5-10 ข้อต่อรอบ แล้ว**ทำต่อรอบถัดไปทันที**:

```
while (มีโจทย์ Pending):
    1. แก้โจทย์ 5-10 ข้อ
    2. บันทึก solutions.md
    3. อัพเดท status → ✅ Solved
    4. อัพเดท index.md stats
    5. ทำต่อทันที! (ไม่ถาม user)
```

### 3. บันทึก AUTO
เมื่อแก้ได้ ให้บันทึกทันที:
- วิธีแก้ → `solutions.md`
- Pattern ใหม่ → `memory/patterns.md`
- Snippet ใหม่ → `memory/snippets.md`

### 4. รายงานผล (เฉพาะตอนจบ)
**รายงานเมื่อ:**
- โจทย์หมดแล้ว
- หรือทำไป 50+ ข้อ (checkpoint)
- หรือติด error

**บอก:**
- แก้ไปกี่ข้อ
- เหลืออีกกี่ข้อ
- ความรู้ใหม่ที่บันทึก

## หมายเหตุ:
- ถ้าโจทย์ง่าย ทำได้ 10-15 ข้อต่อรอบ
- ถ้าโจทย์ยาก ทำได้ 3-5 ข้อต่อรอบ
- Mark ❌ Failed ถ้าแก้ไม่ได้จริงๆ
